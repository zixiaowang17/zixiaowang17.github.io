For b∉H0(b0,η)b\notin H_0(b_0,\eta) it is given by ΔJ(b)=supx∈J(|b(x)−b0(x)|−η)[qb(x)σ2]β2β+1 \Delta_J(b)=\sup_{x\in J}\left(|b(x)-b_0(x)|-\eta\right)\left[\frac{q_b(x)}{\sigma^2}\right]^{\frac\beta{2\beta+1}} which corresponds to the boundary cases b̃=b0±η\widetilde b=b_0\pm\eta.

The second displayed expression omits a positive part. The infimum-of-norms definition is nonnegative, while the displayed supremum can be negative if b leaves the similarity band only outside J. Both original expressions are retained; no correction is silently substituted.
