Theorem 2.2 (Simplified main result)

11 required APIs

Let Tn=naT_n=n^a, ρn=n−b\rho_n=n^{-b} for some a>0a>0, b∈(0,2)b\in(0,2). Then - without computational constraints, the MLSBM is recoverable if 1+a−b>01+a-b>0; and is not recoverable by any algorithm if 1+a−b<01+a-b<0. - assuming the low-degree polynomial conjecture, the MLSBM is recoverable using a polynomial-time algorithm if 1+a/2−b>01+a/2-b>0, and not recoverable by any polynomial-time algorithm if 1+a/2−b<01+a/2-b<0. The above results also hold for detection.
