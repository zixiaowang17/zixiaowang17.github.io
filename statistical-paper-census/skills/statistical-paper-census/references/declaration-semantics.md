# Declaration semantics

The paper's printed label is evidence, not the final Lean representation.

| Paper content | Lean role | Required boundary |
|---|---|---|
| Construction, functional, set, estimator, loss, risk, or fully specified procedure | `definition` | Typed inputs/output and a body or characterizing equation |
| Reusable property such as consistency, privacy, identifiability, or coverage | `predicate` | Stable Prop-valued condition with quantifiers and conventions |
| Bundle with repeatedly used named fields | `structure` | Fields and invariants have meaningful projections |
| Interface intended for inference-driven generic behavior | `class` | Genuine typeclass use, not merely a mathematical class/set |
| Data generated by mathematical constructors | `inductive` | Constructors faithfully express the cases |
| Claim requiring proof | `theorem` | Exact proposition, hypotheses, conclusion, and evidence |
| Result-specific regularity condition | `hypothesis` | Promote only when it has a reusable predicate boundary |
| Symbol, threshold, tuning parameter, or abbreviation | `notation` or `local_object` | Keep local unless it denotes a reusable construction |

A formalizable definition needs a precise Lean type shape, deterministic body or Prop condition,
known domains/quantifiers/edge conventions, and a demonstrated role in a stored main-text theorem.

Common corrections:

- “Estimator” alone is usually a function or kernel type, not a new structure.
- A high-noise or asymptotic regime is normally a hypothesis/predicate.
- An algorithm is a definition only when inputs, outputs, state, and transitions define a function
  or relation.
- A risk bound, consistency guarantee, coverage result, or approximation is a theorem.
- “We define” or `:=` is definition evidence. An equality asserted under assumptions is theorem
  evidence. Notation assignment alone is neither a reusable definition nor a theorem.

In Lean, a Prop-valued `def` is a predicate; a `theorem` is a proof of a proposition. Using a
predicate as a theorem hypothesis does not turn that predicate into a theorem.
